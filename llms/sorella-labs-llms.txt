# Sorella Labs

> Sorella Labs is a crypto-infrastructure company building Angstrom, a decentralized exchange (DEX) built on top of Uniswap V4 that internalizes MEV through application-level sequencing — redirecting value that would normally be extracted by MEV bots and validators back to liquidity providers and swappers. The company also builds Brontes, a Rust blockchain-analytics engine for systematic MEV detection. Backed by Paradigm.

This llms.txt was generated by the API Evangelist enrichment pipeline (2026-07-21) from the provider's public site, docs, and GitHub organization. Angstrom exposes a decentralized JSON-RPC + WebSocket API rather than a REST/OpenAPI surface.

## APIs

- [Angstrom API](https://docs.angstrom.xyz/api/intro): Decentralized JSON-RPC + WebSocket API.
